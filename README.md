# Integrated Embedded Systems & IoT Portfolio 🛠️

This repository serves as an active production log for a systematically deployed portfolio of automation, robotics, and Internet of Things (IoT) prototypes. Updated daily, each module contains fully-functional firmware written in Embedded C/C++ and Python, focusing on sensor integration, real-time data processing, and hardware-to-software communication.

---

### 🎛️ Core Hardware & Protocols Handled
- **Microcontrollers:** Arduino Uno/Mega, NodeMCU (ESP8266), ESP32, Raspberry Pi
- **Protocols & Communication:** MQTT, Wi-Fi (HTTP), I2C, SPI, Serial (UART)
- **Peripherals:** Ultrasonic sensors, RFID readers, Biometric modules, Servo/DC motors, LCD displays
